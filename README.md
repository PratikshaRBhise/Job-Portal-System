# Job Portal System

A full-stack Job Portal web application developed using React.js, Spring Boot, Spring Security, and MySQL. The application provides separate functionalities for Job Seekers, Recruiters, and Administrators.

## 🚀 Features

### 👤 Job Seeker
- User registration and login
- Secure authentication
- Browse and search available jobs
- Apply for jobs
- Upload resume while applying
- Track application status
- View applied jobs

### 🏢 Recruiter
- Recruiter registration and login
- Post new job openings
- View posted jobs
- Manage job postings
- View job applications
- Update application status

### 🛡️ Admin
- Role-based access
- Manage users
- Manage jobs
- Manage recruiters
- Manage applications

### 🔐 Security
- Spring Security authentication
- Role-based authorization
- Password encryption using BCrypt
- OTP-based email verification
- Protected REST APIs
